BJMP NATIONWIDE DOCUMENT AUTOMATION — VERSION 0.9
Separated Document Forms Prototype

WHAT CHANGED
- Separate form prompts for AAR, Memorandum, Memorandum Request, Communication Letter, Spot Report, Progress Report, Minutes, General Order and Special Order.
- Responsive mobile-first form layout and document checklist.
- Preserves the local multi-unit profile prototype and uploaded assets.

IMPORTANT COMPLIANCE NOTE
This is a user-interface and draft-generation prototype, not an officially approved BJMP system. The document generator and each output must be validated against the current controlled national BJMP templates, applicable MCs, approved unit letterhead artwork and current signatory/routing rules before official use.

REFERENCE BASE
- BJMP-OC-MC-133, Communications Policy (publicly available BJMP Regional Office copy; check current amendments).
- BJMP-CDS-MC-147, Brand Identity Manual (verify current official controlled copy and amendments).

No live authentication, server-side data isolation, encrypted backup, or secure multi-device database is provided. Do not enter confidential PDL, personnel, or operational information.
